## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| seleção na tela → corpo do POST de execução | O que o dono desmarcou precisa chegar intacto ao servidor |
| default do checkbox → arquivo criado no disco | Um default errado no tipo B cria `.xmp` que o dono nunca pediu |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-41 | Tampering | Linha desmarcada sendo escrita assim mesmo | mitigate | A CTA envia `Array.from(marcados)`, nunca `null`; o servidor persiste com `aplicar_selecao` e o executor filtra por `incluido`; teste vitest confere os argumentos e teste pytest confere o hash |
| T-06-42 | Tampering | Sidecar `.xmp` criado sem o dono pedir (D-06 é opt-in) | mitigate | Default `incluido=False` vem do servidor (plano 06-03) e o cliente semeia a partir dele em vez de "todos marcados"; teste vitest exige checkbox desmarcado |
| T-06-43 | Repudiation | Formato não suportado sumindo da lista ou aparecendo sem motivo (D-05) | mitigate | O motivo é renderizado como texto visível, não só em `title`; teste assere a string na tela |
| T-06-44 | Repudiation | Falha parcial mostrada como "erro" genérico, impedindo o dono de saber o que entrou | mitigate | Detalhamento obrigatório de 3 segmentos + linha nomeando o campo; caminho do backup surfaceado quando existe |
| T-06-45 | Spoofing | Aviso de pasta sincronizada virando bloqueio silencioso, contrariando D-07 | mitigate | Badge é aditivo; o checkbox permanece marcado; teste vitest confere que fica marcado |
| T-06-SC | Tampering | npm/pip/cargo installs | mitigate | Checkbox e badges são HTML nativo + Tailwind; gate `git diff webapp/package.json` vazio |
</threat_model>
