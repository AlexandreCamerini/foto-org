    Criar `scripts/testar_escrita_exif.py` com shebang `#!/usr/bin/env python3` e
    docstring-contrato no molde do analog, **com a claim de segurança invertida
    e em destaque**: este script NÃO é somente-leitura. Ele escreve — sempre e
    exclusivamente em cópias feitas com `shutil.copy2` dentro de um diretório
    temporário; nunca no `catalog.db`, nunca num arquivo original do acervo. O
    docstring diz o uso (`.venv/bin/python scripts/testar_escrita_exif.py`) e que
    o resultado é registrado em `docs/DECISOES.md`.

    Bootstrap idêntico ao analog: `sys.path.insert(0, str(Path(__file__).resolve().parents[1]))`
    e `from fotoorganizer.config import paths`.

    `argparse` com `--db` (default: caminho de produção via `paths`), `--amostras`
    (int, default 3), `--extensoes` (lista separada por vírgula; default: as
    presentes no catálogo), `--json` (imprime o resultado como JSON além da
    tabela).

    Amostragem: `sqlite3.connect(f"file:{db}?mode=ro", uri=True)`, agrupando
    `media_files` por `extensao` e escolhendo até `--amostras` caminhos por
    extensão, filtrando por `papel='acervo'` e por arquivo que existe em disco.
    Se o catálogo estiver vazio ou inacessível, **sair com código != 0 e
    mensagem explícita** — a medição não pode passar por "nada a testar":
    D-03 exige medição real, e ausência de dado é motivo para parar, não para
    aprovar. Se uma extensão presente no catálogo não tiver nenhum arquivo
    alcançável em disco, registrar essa extensão como `sem_amostra` na tabela.

    Para cada amostra:
    1. `shutil.copy2` para `tempfile.mkdtemp()` — daqui em diante só a cópia é
       tocada. Nenhum caminho de origem é passado a `escrever()`.
    2. `antes = verificacao.dump(copia)`; `avisos_antes = verificacao.avisos(copia)`;
       `meta_antes = PurePythonExtractor().extract(copia)`.
    3. `ExifToolWriter().escrever(copia, {"gps": (-23.55052, -46.633308),
       "cidade": "São Paulo", "pais": "Brasil"})` — os valores sintéticos são os
       mesmos usados na pesquisa; usar o caminho de código de PRODUÇÃO, nunca
       reimplementar a montagem de argumentos aqui (se o script e o produto
       divergirem, a medição não vale nada).
    4. `depois = verificacao.dump(copia)`; `avisos_depois = verificacao.avisos(copia)`;
       `meta_depois = PurePythonExtractor().extract(copia)`.
    5. Veredito da amostra: `aprovado` só quando **todas** as três condições
       valem — (a) `diferenca(antes, depois).inesperadas` está vazio; (b)
       `avisos_depois - avisos_antes` está vazio (delta, não "zero depois" —
       D-04); (c) `meta_depois.largura/altura/data_capturada/model` são iguais
       aos de `meta_antes` (o arquivo ainda abre e continua se lendo igual).
       Registrar, em cada reprovação, qual das três condições falhou e com que
       detalhe (as tags inesperadas, os avisos novos, ou o campo que mudou).
    6. Registrar também, por amostra, quais dos 3 campos entraram
       (`campo_gravado`) — uma extensão pode escrever cidade e recusar GPS.
    7. Apagar o diretório temporário no `finally`, incluindo o `_original` que o
       exiftool deixou.

    Veredito por extensão: `aprovado` só se **todas** as amostras daquela
    extensão foram aprovadas. Uma amostra reprovada reprova a extensão — o
    critério é conservador de propósito.

    Impressão: tabela `extensão | amostras | veredito | motivo` mais um bloco
    final com a linha pronta para copiar para `FORMATOS_APROVADOS` e para
    `MOTIVOS_NAO_SUPORTADO`, para não haver transcrição manual errada.

    Nenhum `shell=True` em lugar nenhum; toda invocação de exiftool passa pelos
    módulos do plano 06-02.
