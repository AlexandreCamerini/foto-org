Rotas (todas em `create_app`, ao lado do grupo `/api/operacoes*`):
- `GET  /api/exif` → `PlanoExif[]`
- `POST /api/exif/plano` → `PlanoExif` (409 `"nada a gravar — todo arquivo catalogado já tem localização preenchida ou não tem valor inferido"`)
- `GET  /api/exif/{plan_id}` → `PlanoExif & { itens: ItemPlanoExif[] }` (404)
- `POST /api/exif/{plan_id}/dry-run` → `RelatorioDryRunExif` (404)
- `POST /api/exif/{plan_id}/executar` — corpo `{"itens": number[] | null}` → estado do job (404, 409)
- `GET  /api/exif/{plan_id}/auditoria` → `LinhaAuditoria[]` (mesma forma já usada por operações)

Formato JSON de plano (`_plano_exif_json`):
`{id, nome, status, dry_run_em, criado_em, total_itens, prontos, problemas,
campos_a_gravar, sidecars, nao_suportados, sincronizados, gravados, com_erro,
executavel}`

Formato JSON de item (`_item_exif_json`):
`{id, media_id, origem, nome, incluido, formato_suportado, motivo_nao_suportado,
sidecar_destino, pasta_sincronizada, erro, backup_original,
campos: {gps: {valor, status, motivo}, cidade: {...}, pais: {...}}}`
— o `valor` do GPS é `[lat, lon] | null`; o de cidade/país é `string | null`.

`JobManager.iniciar_escrita_exif(plan_id: int) -> bool`, tipo de job
`"escrita_exif"`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| corpo HTTP (`itens`) → seleção persistida | Única entrada externa desta fase que influencia o que é escrito no disco |
| `plan_id` da URL → consulta ao banco | Parâmetro de caminho vindo do cliente |
| thread do pedido → thread do job | A seleção precisa atravessar a fronteira sem se perder |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-31 | Tampering | Corpo `{"itens": [...]}` com ids de outro plano incluindo arquivo não revisado | mitigate | `aplicar_selecao` só percorre `ExifWriteItem` do `plan_id` da URL; id de fora simplesmente não casa e o item correspondente fica `incluido=False`; nenhum caminho de arquivo vem do corpo |
| T-06-32 | Tampering | Execução sem dry-run por chamada HTTP direta | mitigate | 409 na rota **e** a dupla porta em `ExifWriteExecutor.executar` (defesa em profundidade — a rota pode ser burlada, o executor não); teste HTTP compara hashes |
| T-06-33 | Elevation of Privilege | Path traversal via parâmetro de rota | mitigate | Nenhuma rota desta fase aceita caminho de arquivo; só `plan_id: int` e lista de ids inteiros. Diferente de `/api/operacoes`, não há campo de destino |
| T-06-34 | Denial of Service | Dois jobs de escrita concorrentes no mesmo plano | mitigate | `JobManager.ocupado()` já serializa; a rota devolve 409 `"já existe um trabalho em andamento"` |
| T-06-35 | Information Disclosure | Servidor exposto fora do loopback | accept | `create_app` já recusa `Host` fora de 127.0.0.1 (`_exigir_origem_local`, comportamento existente e não alterado por este plano) |
| T-06-36 | Repudiation | Auditoria de plano EXIF invisível por causa do `plan_id` NULL | mitigate | Filtro por `detalhe["exif_plan_id"]` no repositório; teste `test_auditoria_do_plano_exif` |
| T-06-SC | Tampering | npm/pip/cargo installs | mitigate | Nenhum pacote novo; nenhum comando de instalação neste plano |
