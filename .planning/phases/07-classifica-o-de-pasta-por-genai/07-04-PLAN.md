<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Navegador (127.0.0.1) → servidor | Corpo JSON com lista de pastas. Único ator é o dono, mas a lista é usada para montar payload externo, então precisa ser reconciliada com as candidatas reais. |
| Servidor → api.anthropic.com | Só atravessa depois dos dois consentimentos. É a fronteira que este plano guarda. |
| UI → flag de consentimento | A UI pode ligar/desligar o opt-in do recurso; não pode ligar a chave mestra. |

| T-07-04-02 | Elevation of Privilege | UI ligando a chave mestra `servicos_externos` sem passar pelo TOML | mitigate | `PUT /api/genai-pasta/config` só escreve `classificacao_pasta_genai`; mestre ligado é pré-condição e devolve 409 quando ausente. Nenhum endpoint escreve `PrivacySettings`. |
