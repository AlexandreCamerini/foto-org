## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-07-01 | Information Disclosure | campo `source_id` em `GET /api/sugestoes` | accept | É a chave primária interna de `Source`, um inteiro sem significado fora do catálogo local. O mesmo cliente já obtém a lista completa de fontes com caminho e apelido em `GET /api/fontes`, e a própria resposta de sugestões já inclui `pasta` (caminho absoluto). O servidor só escuta em 127.0.0.1 (invariante 4 do `CLAUDE.md`) e nada é enviado para fora. Expor o id não aumenta o que o cliente já podia saber |
| T-04-07-02 | Information Disclosure | `title` do selo | mitigate | O texto do `title` fala de nome/data/câmera coincidentes e de fontes diferentes — não expõe caminho absoluto, id nem metadado que a linha já não mostre |
| T-04-07-03 | Spoofing (selo afirmar uma fonte errada) | `rotuloDeFonte(fontes, s.source_id)` | mitigate | A resolução usa a mesma função que `App.tsx` e `Sidebar.tsx` já usam, sobre o mesmo cache; id desconhecido cai no fallback documentado em vez de mostrar um nome arbitrário. O selo só aparece quando `s.source_id != null`, então nenhuma linha ganha atribuição de fonte inventada |
| T-04-07-04 | Tampering | `_sugestao_json` | mitigate | Alteração é aditiva e de leitura pura: uma chave a mais lida de um atributo que a função já acessava. Nenhuma escrita, nenhuma consulta nova, nenhum parâmetro vindo do cliente participa. O teste pytest da Task 1 trava a presença do campo e a integridade dos demais |
| T-04-07-SC | Tampering | npm/pip install | mitigate | Nenhum pacote é instalado nem no Python nem no webapp; `requirements`/`pyproject`/`package.json`/`package-lock.json` fora do diff |

Invariantes do `CLAUDE.md`: catalogação segue somente leitura; nenhuma operação
física é criada ou alterada; nenhum subprocesso; nada sai da máquina.
